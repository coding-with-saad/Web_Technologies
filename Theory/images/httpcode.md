## Http code detail

An HTTP response status code is a three-digit number that a server sends to a browser or client to show the result of a request. You can view a complete List of HTTP status codes on Wikipedia.

The Five Classes of HTTP Codes

The first digit of the code tells you the category of the response:
• 1xx (Informational): The server has received the request and is continuing to process it.
• 2xx (Success): The server successfully received, understood, and processed the request.
• 3xx (Redirection): The client must take extra steps or go to a new address to finish the request.
• 4xx (Client Error): The request has bad syntax or cannot be fulfilled.
• 5xx (Server Error): The server failed to handle a valid request due to an internal issue.

Common HTTP Status Codes

• 200 OK: The request worked, and the server returned the requested data.
• 201 Created: The request worked and created a new resource.
• 301 Moved Permanently: The requested page has a new permanent URL.
• 302 Found: The requested page is temporarily at a different URL.
• 400 Bad Request: The server could not understand the request because of bad syntax.
• 401 Unauthorized: You need to log in or provide valid credentials to see the page.
• 403 Forbidden: The server knows who you are, but you do not have permission to view the page.
• 404 Not Found: The server cannot find the requested page or file.
• 429 Too Many Requests: You are sending too many requests too fast and hit a rate limit.
• 500 Internal Server Error: The server hit an unexpected condition and could not finish the request.
• 503 Service Unavailable: The server is down for maintenance or is too busy to handle the traffic.
