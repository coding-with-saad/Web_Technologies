# 2. What does it mean to know enough to build a good project?

Let's take a practical example. Suppose you want to build a Smart Campus Student Portal with AI assistance.

You need a login page, dashboard, attendance system, timetable, and student profile.

You don't need to remember every CSS property or write every line of JavaScript from scratch. But you should understand the following:

| Task                      | What you need to understand                           |
| ------------------------- | ----------------------------------------------------- |
| Describe the requirements | What the application should do and who will use it    |
| Generate the UI with AI   | HTML structure, CSS layout, responsive design         |
| Add functionality         | JavaScript logic, events, forms and validation        |
| Build with React          | Components, state, props and data flow                |
| Connect a backend         | HTTP requests, APIs, authentication and databases     |
| Debug problems            | Read error messages, inspect code and test fixes      |
| Prepare for real users    | Security, permissions, data validation and deployment |

Notice something important: you need more than coding knowledge. You need software development knowledge.

For example, if AI creates a login form that looks excellent but stores passwords in plain text, you need enough understanding to recognize that it's unsafe. If the dashboard shows incorrect attendance, you need to trace where the data comes from rather than just asking AI to change the design.

That's the difference between someone who can generate code and someone who can develop a reliable application.

## Three levels of knowledge

Level 1 — Understand

You can explain what the code does, identify the important parts, and make small changes with guidance.

Enough for simple projects and coursework with AI assistance.

Level 2 — Build and debug

You can break a project into features, guide AI, connect components, diagnose common bugs, and verify that the features work.

Your immediate target

Enough to build useful full-stack applications with AI as your coding assistant.

Level 3 — Engineer independently

You can make architectural decisions, handle complex failures, review security, optimize performance, test thoroughly, and maintain production systems.

The longer-term target for professional software engineering.

You can start building useful projects at Level 1 and progressively reach Level 2. You don't have to wait until you become an expert.

# 3. Does web development have a future in the age of AI?

My honest answer: web development has a future, but the value of different web development skills is changing.

Your concern is reasonable. AI can already generate landing pages, forms, dashboards, CRUD applications, and considerable amounts of frontend and backend code.

The latest Stack Overflow Developer Survey for 2026 reports that 83% of respondents use at least one AI tool, with coding assistants among the most widely used. However, developers still emphasize checking AI output rather than trusting it blindly.&#x20;

Here is how I would interpret the changes.

Work becoming easier to automate

- Basic static websites
- Repetitive HTML and CSS
- Standard forms and CRUD code
- Boilerplate components
- Simple changes that are clearly specified

Skills that remain important

- Turning unclear requirements into working software
- Designing the right database and application architecture
- Debugging complex problems
- Security, testing and reliability
- Integrating APIs, AI models and external services

# 5. What I would recommend you do now

Since your instructor is already teaching HTML, CSS, JavaScript, React and PHP, I wouldn't recommend abandoning the subject. Instead, change how you approach it.

Here is a practical six-week learning plan, assuming you can spend roughly 45–60 minutes a day outside class.

Week 1

HTML and CSS

Build one page with a navbar, cards, a form and a responsive layout.

Week 2

JavaScript fundamentals

Practice variables, conditions, loops, functions, arrays and objects.

Week 3

Interactive JavaScript

Add form validation, button events, DOM manipulation and local storage.

Week 4

React basics

Build a small dashboard using components, props, state and forms.

Week 5

Backend and databases

Understand HTTP, APIs, CRUD operations, authentication concepts and basic PHP.

Week 6

Complete a small project

Combine what you learned into a task manager or student dashboard; use AI for help and test every feature.

This is a starter plan, not a promise of mastery in six weeks. The objective is to build a foundation you can continue developing.

For each concept, use this learning cycle:

1. Understand the concept with a small example.
2. Write or modify the code yourself.
3. Ask AI to explain the code and why it works.
4. Introduce a small change without copying the original solution.
5. Debug the errors you encounter.
6. Build one small feature that uses the concept.

One rule I strongly recommend: never accept code from AI that you cannot explain at a basic level. You don't have to memorize every line, but you should understand what the important parts do, what data they use, and how you would test them.

# 6. The most important distinction

There are two different goals, and they require different levels of expertise.

| If your goal is…               | Your priority should be…                                                              |
| ------------------------------ | ------------------------------------------------------------------------------------- |
| Pass your university course    | Understand the concepts, write basic code and answer viva questions                   |
| Build projects with AI         | Understand requirements, code structure, debugging, APIs and databases                |
| Get a software development job | Develop stronger fundamentals, testing, security and collaborative development skills |
| Become an AI engineer          | Prioritize Python, software engineering, AI concepts, APIs and deployment             |
| Become a blockchain developer  | Prioritize programming, smart contracts, security and blockchain fundamentals         |

You don't need to pursue all five simultaneously.

My recommendation for you is to learn enough web development to become capable of building and understanding a complete application, while keeping AI engineering as your primary area of exploration. That lets you satisfy your course requirements without committing your entire career to something you don't enjoy.

One final thought: in this era, the most useful person is not necessarily the one who types code the fastest. It's the person who can identify the right problem, decide what should be built, use AI effectively, recognize when the result is wrong, and deliver something that actually works.

That is the skill worth developing.
